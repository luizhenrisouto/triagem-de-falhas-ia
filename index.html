Código no GitHub Issues abertas pela IA

Carregando os resultados…

Todo dia, uma suíte de testes roda contra o SauceDemo, uma loja feita para treino de QA. Algumas falhas foram plantadas de propósito, com a resposta certa guardada em um gabarito. Cada falha vai para um fluxo no n8n, a IA (Gemini, ou Claude se configurado) decide a causa e, quando é defeito, abre ou atualiza uma issue sem repetir.
